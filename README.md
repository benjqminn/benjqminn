## 🧪 Featured Projects

### ☁️ Forensic Visibility in AWS

Graduate research evaluating how AWS-native logging reconstructs simulated attacker activity. Built a controlled AWS environment, correlated evidence across multiple logging sources, and documented timelines and SHA-256 evidence verification.

Across **87 simulated actions**, the study measured **87.4% overall observability** and **63.2% strict full reconstruction**. The results highlighted gaps that required correlation beyond CloudTrail alone.

### 💸 Trace — Financial Intelligence Platform

Computer Science capstone built with React, FastAPI, MySQL, Redis, and AWS to help users analyze transactions, forecast spending, and explore financial decisions.

My contributions focused on backend intelligence systems, AWS deployment, authentication and security hardening, monitoring, structured logging, and deployment reliability.

### 🔍 Obscura — PCAP Analysis & Threat Detection

Solo SOC simulation built with Flask, React, PyShark, and YARA. Analyzes uploaded PCAP files, flags suspicious activity such as SYN scans and brute-force attempts, and presents alerts for analyst-style triage.

[View the project overview and screenshots](https://github.com/benjqminn/obscura-project)
